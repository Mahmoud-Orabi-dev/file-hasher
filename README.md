# File Hasher

A Python tool that computes file hashes and verifies file integrity.

## Features

- Computes the SHA-256 hash of any file
- Handles large files safely by reading in chunks
- Verifies a file against an expected hash

## Requirements

- Python 3.8 or newer
- No extra libraries needed

## Usage

```
python file_hasher.py myfile.zip
python file_hasher.py myfile.zip <expected_sha256>
```
